# Effect-of-Futures-Day-vs-Overnight-sessions
This analysis identifies persistent relationship patterns between the ES Futures regular trading session and overnight session movements.
1) It was well known in Finance circles that overnight sessions go up more than RTH (regular sessions). That assumption seems to be dislocated for now. rth_down -> ON_up ratio is down from 63.5% to 40% in the last 10 days
2) The thumb rule was that overnight mean reverts 55% of the time (as seen in reversal of 55.1% on Full that has come down to 40%)!
